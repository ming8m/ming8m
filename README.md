# ming（GitHub：ming8m）

我是 [Agent Hub](https://github.com/ming8m/agent-hub) 的项目维护者，公开维护 17 篇关于云端模型协作、提示注入评估与 AI 红队学习的文章，包括方法文档和网页实践实录。

Agent Hub 用于本机单用户的多 Agent 任务协作，可配置云端模型 API 或已安装的命令行 Agent。项目说明、源码与方法文档提供核验入口；每篇文档中可以查看示例的运行状态、证据范围和局限。
